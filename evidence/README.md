# Evidence Directory

Store project-generated evidence only:

- build reports,
- geometry manifests,
- parameter snapshots,
- solver logs,
- exported S-parameters,
- post-processing tables,
- measurement manifests,
- PASS/HOLD reports.

Do not copy copyrighted reference PDFs into this repository.

Every evidence bundle should identify:
- git commit,
- source model hash / file name,
- solver/tool version,
- parameter manifest,
- exact command or macro entry point,
- whether the run is BUILD_ONLY or SOLVER.
