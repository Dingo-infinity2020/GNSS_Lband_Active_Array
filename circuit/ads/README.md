# ADS Circuit Track

Circuit simulation is intentionally deferred until the passive reconstruction and L-band array source-impedance problem are defined.

## R4 planned work

Reference branch:
- 2 x QPL9547 per balanced polarization,
- differential source sweep,
- noise figure / equivalent noise temperature,
- transducer gain,
- amplitude and phase imbalance,
- differential and common-mode stability,
- out-of-band stability.

The source is not fixed to 100 ohm.

Initial exploratory differential source range:
- 80–160 ohm real-axis baseline,
- then complex impedance clouds exported from CST R3.

A lower-cost LNA candidate shall be evaluated only after the reference model and measurement method are stable.

No ADS result may be used to justify R0 geometry.
