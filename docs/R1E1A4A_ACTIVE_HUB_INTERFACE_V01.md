# R1E1A4A Active-Hub / Support Interface V0.1

Status: DESIGN FREEZE CANDIDATE — NO CST BUILD/SOLVE AUTHORIZATION

## Architectural correction

The active hub is not a competitor to PTFE/foam/PCB/metal support families. It is the receiver interface that the final antenna is expected to require.

The design space is therefore decomposed into:
1. mandatory source-facing active-hub architecture H0;
2. mechanical carrier/support family Sx from the hub/radiator assembly to the main backplane.

This prevents us from comparing unlike objects such as "PCB hub versus PTFE standoff".

## H0 — backside-integrated active-hub baseline

Use the underside of the existing radiator PCB as the first source-facing active-hub carrier rather than introducing a second full PCB at this stage.

Project-owned baseline envelope:
- hub source-facing envelope: 11.0 x 11.0 mm centered at x=y=0;
- initial local-ground island: 10.0 x 10.0 mm centered on the underside of the radiator PCB;
- 10-mm ground square corner radius = 7.071 mm, leaving ~1.50 mm radial clearance to the 8.571-mm inner-slot start radius;
- no claim is made that this reproduces hidden CHARTS center geometry.

Why this baseline:
- fits within the project-owned center geometry with explicit margin;
- is close to the electromagnetic scale of the published CHARTS center-region dimension without claiming identical semantics;
- can fit four 2x2-mm QPL9547-class packages or equivalent footprints in a fourfold-symmetric arrangement;
- avoids a second dielectric board before the first EM co-design gate.

## RF terminal transfer

Each of the four top-copper terminal regions may be transferred to the underside hub through one project-owned RF via / plated feed feature centered on the existing terminal reference region.

First manufacturable via envelope for later BUILD review:
- finished drill: 0.30 mm;
- RF pad diameter: 0.80 mm;
- local-ground anti-pad diameter: 1.20 mm;
- exact fabrication rules must be checked against the selected PCB vendor before BUILD freeze.

All four feed features must be generated by exact 90-degree rotation from one master.

No independently tuned per-polarization feed geometry is permitted before a quantified asymmetry study.

## P0 and P1 reference planes

P0 remains the existing ideal differential plane between opposite radiator terminal centers.

For the future mixed-mode passive model, replace the single P0 differential excitation by two single-ended ports for one polarization:
- P1A: RF input pad/feed feature at terminal A referenced to the H0 local ground;
- P1B: RF input pad/feed feature at terminal B referenced to the same H0 local ground.

P1A/P1B are defined at the source-facing LNA input pad plane, before the active device.

The first P1 model intentionally omits transistor behavior. It exists to extract:
- the two-port single-ended impedance/S matrix;
- Zdd/Sdd differential mode;
- Zcc/Scc common mode;
- differential/common conversion;
- branch imbalance and local-ground current.

Only if the resulting nominal symmetric model demonstrates a valid virtual-ground approximation may `Z_branch = Z_diff/2` be promoted from diagnostic assumption to qualified simplification.

## Package / shield keepout

QPL9547 G0 package envelope: 2 x 2 mm.

The nominal H0 layout reserves one identical package/ground cell in each quadrant. Package orientation must be generated by exact 90-degree rotations.

Initial shield envelope for later EM design:
- maximum source-facing footprint: 12 x 12 mm;
- shield is directly bonded to the H0 local ground through multiple short perimeter contacts/vias;
- the output-coax ground must not be the sole RF return for the shield.

The shield envelope is not yet an authorized CST object.

## Mechanical carrier families below H0

C0 — bonded low-density foam reference:
retain the existing S1 science data as a low-epsilon reference, not production default.

S1 — central dielectric tube / standoff main comparator:
PTFE-class or PEEK-class hollow/solid support centered beneath the H0/shield region. A hollow symmetric carrier is preferred for cable/bias routing and reduced dielectric volume. Exact OD/ID/grade/attachment geometry is not yet frozen.

C2 — PCB / printed structural frame:
use one or more symmetric dielectric PCB ribs or frame pieces only if they provide a clear assembly or routing advantage. Copper on a structural PCB is an RF object and cannot be treated as transparent.

C3 — grounded metal tube/frame:
allowed only as an intentional RF/mechanical structure tied to the local-ground/shield design. It is not a transparent-support candidate.

## Stability-specific mechanical rule

Because QPL9547-class gain is ~20 dB and published user experience shows shield/ground return geometry can create feedback-sensitive oscillation, the shield/local-ground connection is part of the RF stability model, not a mechanical afterthought.

For H0, shield grounding must be local and short; remote grounding through the output-coax connector is not an acceptable default architecture.
