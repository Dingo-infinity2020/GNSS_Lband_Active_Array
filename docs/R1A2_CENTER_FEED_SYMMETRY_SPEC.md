# R1A2 Center Feed / Polarization Symmetry Contract

Status: **DESIGN RULE FROZEN; NUMERICAL FEED PAD GEOMETRY NOT YET FROZEN**

This document prevents the symmetry failure seen in the REF-CUI proxy reconstruction.

## Coordinate system

- radiator plane: XY
- +Z: sky / boresight
- X polarization: differential pair on +/-X directions
- Y polarization: differential pair on +/-Y directions

## Canonical-construction rule

Only one local feed/terminal arm geometry may be authored manually:

`FEED_X_PLUS_MASTER`

All other terminals and their local isolation geometry must be generated by exact rotations about the origin:

- `FEED_Y_PLUS = Rz(+90 deg) * FEED_X_PLUS_MASTER`
- `FEED_X_MINUS = Rz(180 deg) * FEED_X_PLUS_MASTER`
- `FEED_Y_MINUS = Rz(270 deg) * FEED_X_PLUS_MASTER`

No independent X-/Y+/Y- polygon authoring is allowed.

## Differential pairing

- X differential port later connects X+ against X-
- Y differential port later connects Y+ against Y-
- no analog 90-degree hybrid
- no single-ended 50-ohm feed is inserted merely for convenience

## Geometry audit requirement

Before any solver:
- rotational geometry equality must be machine-checked,
- corresponding terminal/pad areas must match,
- corresponding radial distances must match,
- gap widths must match under 90-degree rotation,
- X/Y metal-volume or sheet-area mismatch must be below numerical construction tolerance.

## R1A1 relationship

R1A1 deliberately does **not** instantiate this feed.

R1A1 only proves the source-visible aperture scales deterministically to L band.

Numerical feed-pad/neck dimensions will be frozen in R1A2 as PROJECT_DESIGN after R1A1 build review.

## Active-electronics rule

The eventual active hub may break purely mechanical fourfold symmetry because components/connectors need routing, but the **RF terminal geometry before first-stage LNA inputs must preserve exact X/Y rotational symmetry** unless a later quantified exception is approved.

QPL9547 remains a reference LNA candidate; no LNA is included in R1A1/R1A2 passive build-only.
