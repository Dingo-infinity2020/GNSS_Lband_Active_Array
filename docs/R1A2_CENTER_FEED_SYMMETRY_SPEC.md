# R1A2 Center Feed / Polarization Symmetry Contract

Status: **DESIGN RULE + NUMERICAL BASELINE FROZEN FOR REVIEW; NO BUILD AUTHORIZATION YET**

R1A2 is a project-owned feed geometry. It is not claimed to reproduce hidden CHARTS feed details.

## 1. Coordinate system

Board axes:
- +X / -X: PCB edge directions
- +Y / -Y: orthogonal PCB edge directions
- +Z: boresight / sky

Because the accepted CHARTS-inspired aperture is divided by cross-shaped inner slots, the four petal sectors occupy the four quadrants.

Therefore the natural orthogonal polarization axes are diagonal:

- **Pol-A**: NE <-> SW, axis angle +45 deg / +225 deg
- **Pol-B**: NW <-> SE, axis angle +135 deg / +315 deg

The backend may later rotate calibrated Pol-A/Pol-B voltages into any desired X/Y basis before RHCP/LHCP synthesis.

## 2. Exact rotational construction rule

Only one canonical terminal/center-gap geometry may be authored manually.

Canonical quadrant:
- `PETAL_TERMINAL_MASTER_NE`

Other quadrants must be generated only by exact Z-axis rotations:

- NW = Rz(+90 deg) * NE
- SW = Rz(+180 deg) * NE
- SE = Rz(+270 deg) * NE

No separately authored NW/SW/SE terminal polygon is allowed.

The same rule applies to:
- center isolation gap,
- terminal contact reference region,
- any future via/probe footprint before the first-stage LNA.

## 3. Center isolation-gap baseline

R1A2 introduces a **copper/electrical isolation gap**, not a mechanical PCB cut.

For the BUILD-ONLY geometry baseline:

- `feed_gap_center_width = 1.20 mm`
- `feed_gap_outer_width = 2.571428571 mm` (= R1A1 inner-slot width)
- `feed_gap_join_radius = 8.571428571 mm` (= R1A1 inner-slot start radius)

One master gap extends radially from the center toward +Y in board coordinates and tapers from 1.20 mm at the center to the existing 2.5714 mm inner-slot width at the join radius.

The other three center-gap arms must be generated by exact 90-degree rotations.

This makes the hidden center-feed geometry explicitly PROJECT_DESIGN while preserving the accepted visible slot family.

## 4. Terminal contact-reference baseline

The four RF contact regions lie on the diagonal petal axes.

One canonical NE contact zone is defined in local coordinates:

- radial center: `terminal_r = 3.00 mm`
- radial length: `terminal_len = 2.00 mm`
- tangential width: `terminal_w = 1.60 mm`

Thus the canonical contact zone spans approximately:
- radius 2.00 to 4.00 mm,
- centered on +45 deg.

The other three contact zones are exact 90-degree rotations.

These contact zones are **reference regions for later feed/LNA integration**. R1A2 does not create ports or LNAs.

## 5. Differential pairing

- Pol-A differential pair: NE terminal against SW terminal
- Pol-B differential pair: NW terminal against SE terminal

No analog 90-degree hybrid.

No 50-ohm single-ended interface is inserted before the first-stage active device merely for convenience.

## 6. Symmetry audit

Before any solver, a geometry audit must verify:

- four center-gap arms are exact 90-degree rotations,
- terminal reference centers have equal radius,
- terminal areas are equal,
- gap center widths are equal,
- outer join widths/radii are equal,
- no independently authored quadrant geometry exists,
- Pol-A and Pol-B differ only by a 90-degree rotation.

Recommended CST construction:
- create one master gap tool,
- use `Transform` Rotate with origin at (0,0,H),
- copy with repetitions / exact 90-degree angle,
- subtract generated copies from the aperture.

## 7. Mechanical active-hub note

The eventual shield/LNA board behind the radiator may have routing asymmetry.

That mechanical asymmetry is allowed only **after** the RF terminal geometry is frozen and must not alter the four source-facing terminal geometries without an explicit quantified exception.

## 8. Current stop boundary

R1A2 is currently DESIGN only.

No build, port, solver, material choice, LNA, or optimization is authorized until the master-gap/terminal construction is reviewed and entered into the stage contract.
